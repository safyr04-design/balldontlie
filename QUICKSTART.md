# Ball Don't Lie Lab - Quick Start

Welcome to the Ball Don't Lie Lab sports betting analysis system! 🏀

## ⚡ Quick Setup (5 minutes)

```bash
# 1. Install dependencies
cd /home/user/webapp/backend
pip install -r requirements.txt

# 2. Set your API key
export BDL_API_KEY="your-api-key-here"

# 3. Run the demo
python main_demo.py guide

# 4. Create your first model
python main_demo.py create

# 5. Start automated monitoring
python prediction_monitor.py start
```

## 📚 What You Get

- ✅ **Complete Python SDK** - All API endpoints covered
- ✅ **9 Pre-Built Strategies** - Ready-to-use betting models
- ✅ **Automated System** - Set it and forget it
- ✅ **Factor Analysis** - Deep insights
- ✅ **React Dashboard** - Modern UI

## 🎯 Common Commands

```bash
# Show available strategies
python backend/model_strategies.py

# Analyze factors
python backend/factor_analyzer.py recommend nba spread

# Monitor models
python backend/prediction_monitor.py add 123
python backend/prediction_monitor.py start

# View high-confidence picks
python backend/prediction_monitor.py picks 0.7
```
